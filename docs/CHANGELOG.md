# 更新记录

本项目遵循语义化版本。所有重要变更记录于此。

---

## v0.1.0 — 首个发行版

首个公开版本，Windows x64。

### 新功能
- **F1 划词翻译**：选中文本一键翻译。
- **F2 打字翻译并回贴**：输入后回车把译文粘贴回原窗口。
- **F3 截图 OCR 翻译**：框选屏幕区域，本地 OCR 识别 + 翻译，结果可贴图置顶、支持翻译覆盖图。
- **F4 新建文件夹**：`Enter` 译名 / `Esc` 原名 / `Delete` 取消。
- **F5 主窗口**：双栏翻译、翻译历史、全部设置。
- **三级引擎**：OPUS / NLLB（CTranslate2）+ GGUF 大模型（llama.cpp，Hy-MT2-1.8B），可排序与回退。
- **内置模型市场**：索引化语言包，一键下载 / 卸载。
- **智能内存管理**：闲置自动释放大模型与 NLLB（可配置）。
- **游戏模式**：前台全屏游戏时自动禁用热键。
- **可自定义全局热键**（F1–F5）。
- **托盘常驻**、开机自启、浅色 / 深色 / 跟随系统主题。
- **更新检查**：启动静默检查 GitHub Releases，仅提示不自动下载。

### 工程
- 基于 Tauri 2 + Rust + 原生 WebView2，安装包约 11 MB。
- 安装向导支持选择**首选 / 次选语言**，并可预设闲置释放、历史条数、外观主题、游戏模式、快速引擎、贴图选项等偏好（写入 `settings.json`）。
- 除更新检查外完全离线，OCR 使用系统 `Windows.Media.Ocr`。
- `vendor/` 内嵌 llama.cpp 本地补丁，统一 MSVC 静态运行库（`+crt-static`）。

### 修复
- 大模型闲置卸载计时在收到第二条命令后被旁路的问题。
- `auto` 源语言下非中文脚本被误标为英文的问题。
- 模型市场下载文件名未校验导致路径穿越的问题。
- 弹窗翻译 / 回贴的并发竞态（重复回车、过期响应）。
