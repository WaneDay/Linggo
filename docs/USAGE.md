# 使用说明

本文详细介绍 Linggo 的每个功能与全部设置项。若只想快速上手，先看 [主 README 的快捷键一览](../README.md#快捷键一览简略使用教程)。

---

## 1. 安装与首次运行

### 安装
1. 运行 `Linggo-Setup-x.y.z.exe`。
2. 向导中可设置：
   - **首选语言 / 次选语言**（安装时校验两者不能相同）；
   - **偏好设置**：闲置释放、历史条数、外观主题，以及游戏模式、快速引擎、回退大模型、贴图覆盖图、贴图提示等；
   - 附加任务：创建桌面快捷方式、开机自启。
3. 安装完成后 Linggo 常驻系统托盘。

> 上述偏好写入 `%APPDATA%\Linggo\settings.json`，之后可在软件「设置」中随时修改；重新安装时若不勾选「覆盖已有设置」，将保留原配置。

### 首次运行需要准备模型
Linggo 本体不带模型。打开主窗口（默认 `F5`）后有两种方式：

- **模型市场**：设置 → 模型市场 → 点对应语言包「下载」，自动安装到 `models/`。
- **手动指定**：设置 → 模型 → 模型文件「浏览…」选择本地 `.gguf` → 「加载」。

即使不加载大模型，只要安装了 OPUS / NLLB 语言包，F1–F4 也能用快速引擎翻译。

## 2. 各功能详解

### F1 · 划词翻译
1. 在任意程序里用鼠标选中一段文本。
2. 按 `F1`（默认）。
3. 弹窗显示「原文 / 译文」，可一键复制。

原理：向原窗口发送 `Ctrl+C` 复制选区，然后读取剪贴板。因此**目标程序必须支持复制快捷键**；部分终端、远程桌面、带反作弊的游戏会拦截 `Ctrl+C`，此时 F1 无法取词，请改用 F2。

### F2 · 打字翻译并回贴
1. 按 `F2` 弹出输入框。
2. 输入内容，按 `Enter`。
3. 译文生成后会自动「粘贴 + 回车」到刚才的窗口。

适用于聊天框、搜索框等无法选中文本的场景。翻译过程中会阻止重复回车，避免错乱；`Esc` 关闭不发送。

### F3 · 截图 OCR 翻译
1. 按 `F3`，屏幕变暗进入框选。
2. 按住鼠标拖拽框选要识别的区域，松开即开始识别翻译。
3. 结果显示在一个**可贴图置顶**的窗口：
   - 可查看原文 / 译文；
   - 可切换「翻译覆盖图」在原图上叠加译文；
   - 可关闭快捷键提示。

识别语言在「设置 → OCR → 识别语言」中选择（自动 / 中文 / 英文 / 日文 / 韩文 / 德 / 法 / 西 / 意 / 葡 / 俄）。

### F4 · 新建文件夹
1. 在文件资源管理器或桌面上，把鼠标移到想创建的位置。
2. 按 `F4` 弹出命名框，输入名字后：

| 操作 | 结果 |
| --- | --- |
| `Enter` | 用**翻译后**的名字创建文件夹 |
| `Esc` | 用**原始输入**的名字创建文件夹（不翻译） |
| `Delete` | 取消创建并关闭弹窗 |

创建成功后会自动刷新资源管理器（F5 的模拟）。

### F5 · 主窗口
- 顶部语言栏：源语言 / 目标语言、`⇄` 交换、复制、翻译、历史、设置。
- 主体：左「原文」右「译文」双栏；`Ctrl+Enter` 翻译。
- 底部状态栏：模型状态、游戏模式提示、版本号。
- 右下角圆钮：检测到新版本时出现，点击打开发布页。
- 关闭主窗口 = 收到托盘（不退出）。

### 系统托盘
- **左键单击**：显示 / 隐藏主窗口。
- **右键**：菜单「打开主窗口 / 退出」。

### 翻译历史
主窗口 → 历史。保存最近的翻译对，条数由「设置 → 通用 → 历史条数」控制（0 表示不记录）。可一键清空。

## 3. 设置项一览

### 模型
| 项 | 说明 |
| --- | --- |
| 模型文件 | 选择 `.gguf` 大模型路径 |
| 浏览 / 加载 / 释放内存 / 清空路径 | 管理当前加载的大模型 |

### 快速翻译引擎（NMT · OPUS / NLLB）
| 项 | 说明 |
| --- | --- |
| 启用快速翻译引擎 | 关闭后只用 GGUF 大模型 |
| 引擎排序 ①②③ | F1–F4 按此顺序尝试（默认 OPUS → NLLB → GGUF） |
| F5 主窗引擎 | 单独指定主窗口引擎（默认 GGUF） |
| 释放 NMT 内存 | 立即回收 NLLB（约 1.4 GB）；OPUS 常驻缓存 |
| OPUS zh→en / en→zh 路径 | 指定语言包目录，留空自动发现 |
| NLLB 模型目录 | 选择含 `model.bin` 的目录 |
| NMT 不可用时回退大模型 | 勾选后快速引擎失败会转用 GGUF |

### 翻译方向（F1–F4 自动选择目标语言）
| 项 | 说明 |
| --- | --- |
| 首选语言 | 默认 `zh`（中文） |
| 次选语言 | 默认 `en`（英文） |

规则：识别到**首选语言** → 译为次选；识别到**其他语言** → 译为首选。

### 模型市场（Package Index）
- 索引地址留空使用内置索引（`src-tauri/pkg_index.json`）。
- 可填自定义索引地址后「刷新列表」。
- 「可用语言包」点下载即装到 `models/`；「已安装」删除即卸载。

### 通用
| 项 | 说明 |
| --- | --- |
| 闲置释放 | 大模型无操作后自动卸载：5 / 15 / 30 秒，或「不释放」常驻。默认 15 秒 |
| 历史条数 | 0 / 20 / 50 / 100 / 200，默认 50 |
| 外观 | 跟随系统 / 浅色 / 深色 |
| 开机自启 | 登录后静默启动到托盘 |

### 软件更新
- 「启动时自动检查新版本」：关闭后启动不再检查；设置页「检查更新」按钮仍可手动检查。
- 仅提示，不自动下载；有新版本时弹托盘气泡并在主窗口显示圆钮。

### OCR
| 项 | 说明 |
| --- | --- |
| 识别语言 | F3 截图识别的语言 |
| 贴图默认显示翻译覆盖图 | 贴图打开时直接叠加译文 |
| 贴图显示快捷键提示 | 是否显示贴图操作提示 |

### 全局热键
可分别修改 F1–F5 的按键组合。

### 游戏模式
「前台为全屏游戏时自动禁用热键」：避免在游戏中误触 F1–F5。

### 关于
显示版本号与「完全离线」说明。

## 4. 数据与配置位置

| 内容 | 位置 |
| --- | --- |
| 设置 | `%APPDATA%\Linggo\settings.json` |
| 历史 | `%APPDATA%\Linggo\history.json` |
| 模型 | 可执行文件旁的 `models\`（软件内下载默认装到此处） |

> 删除 `%APPDATA%\Linggo` 可恢复出厂设置（会丢失历史与偏好）。

---

## 5. 使用小贴士

- 中英互译优先走 OPUS，速度几乎瞬时；需要更自然的文风时在主窗口切到 GGUF。
- 长时间不用大模型时保持「闲置释放」开启，可省下约 1 GB 内存。
- 全屏游戏里误触热键 → 保持游戏模式勾选。
- F2 回贴依赖前台窗口未改变，翻译期间不要切换窗口。
